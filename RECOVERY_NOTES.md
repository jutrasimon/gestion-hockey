# Notes de récupération — v21

## Constat

Le 19 septembre 2026, le dépôt GitHub `jutrasimon/gestion-hockey` ne contenait qu'une branche `main` avec un seul fichier `README.md` minuscule. Aucun fichier HTML, CSS, JavaScript, TypeScript ou asset du site n'était présent.

La version publiée v21 était encore identifiable sous le nom **Hockey Club Lab**, avec l'URL `hockey-candy-gym.jutrasimon.chatgpt.site` et le contenu de l'interface indexé.

## Éléments récupérés / reconstruits

- Navigation : Mon club, Équipe, Contrats & finances, Observatoire, Stats avancées, Mes favoris, Glossaire, Gym · Validation.
- Québec, saison 2028–2029.
- Premier trio et banc.
- Six joueurs de démonstration : Émilie Roy, Alexis Gagnon, Viktor Sokolov, Sarah Fortin, Hugo Leclerc et Jules Morin.
- Attributs : MAN, TIR, PUI, PAT, IQ, CRÉ, CŒ.
- Contrats, statut de santé et statistiques de saison.
- Fiche détaillée avec potentiel, personnalité/culture, contrat et expérience.
- Favoris, filtres, tableau comparatif et drag-and-drop.
- Direction d'interface sombre, moderne, responsive.
- Couleurs centralisées; aucune couleur fonctionnelle n'est volontairement hardcodée dans les composants JS.

## Limites

Ce dossier est une **reconstruction fonctionnelle**, pas un dump bit-à-bit de l'ancien projet ChatGPT Sites. Le code source original n'étant pas présent dans le dépôt et aucun export de projet n'ayant été retrouvé, certains détails internes de l'implémentation originale peuvent différer.

Cette archive est conçue pour devenir la nouvelle source de vérité locale/Git.
